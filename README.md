# 📈 Asia Age-Specific Fertility Trends Dashboard (Tableau Project)

This Tableau project explores **age-specific fertility patterns** across Asian countries using curated datasets. The goal is to highlight regional demographic trends and provide meaningful insights into how fertility rates vary by age group and country.

## 📊 Project Overview

The analysis is based on datasets covering:
- Fertility rates by age group (Excel source)
- A list of Asian countries for regional filtering
- Interactive Tableau dashboards that allow comparisons across age groups and countries

This project was completed as part of a final group assignment for BIS582 (Business Intelligence and Analytics).

---

## 📁 Files Included

- `BIS582-Final Project-group 5.twbx` — Tableau workbook containing all dashboards
- `Age Specific Fertility Rate. 582(1).xlsx` — Dataset of fertility rates by age group
- `Asia_Countries_List 582(2).xlsx` — Regional dataset for country-based analysis

---

## 🔍 Key Insights

- Fertility trends differ sharply between countries and age groups.
- Countries in South and Southeast Asia have higher fertility in younger age brackets.
- The visual breakdown helps uncover regional disparities and supports targeted health and development policies.
